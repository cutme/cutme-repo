LTL / Biobank

Front-end coding & WordPress implementation for two graphic designs.

Brief

The LTL Biobank projects required coding modern, responsive interfaces from supplied graphic designs and implementing them as WordPress themes. The sites needed to be readable, fast and accessible on all devices, while allowing easy content management by the administrator.

My role

I was responsible for the front-end layer and WordPress implementation. I collaborated with the design team to ensure faithful layout reproduction and high code quality.

  • Pixel Perfect front-end coding from graphic designs
  • Semantic HTML and organised CSS structure
  • WordPress themes with editable content areas (ACF)
  • GSAP animations and interactive interface elements
  • Full responsiveness – mobile, tablet, desktop
  • Performance optimisation and clean code
